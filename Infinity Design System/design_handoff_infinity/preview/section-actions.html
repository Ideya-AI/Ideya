Content

  • 6–14 real options across the six types.
  • Each: type · title · one-line what-it-is · optional position tag.
  • Spans every position with an on-ramp + unaligned options.
  • Vetted, real orgs/links — credibility signal where it helps.

Design

  • Type icon leads each card; alignment tag in the position's color.
  • All actions are equal-weight cards — no primary CTA.
  • Outbound ↗ mark; these leave the product.
  • Poster: type chips only. Web: grid. Mobile: grouped-by-type list.

Interaction & rules

  • No endorsement, ever — order by type, never by “recommended.”
  • Filter by type or by position (“show me Cost-Skeptic actions”).
  • Submit your view opens the one inbound action (feeds Positions).
  • “Learn more” is the Going-Further axis surfacing as an action.
