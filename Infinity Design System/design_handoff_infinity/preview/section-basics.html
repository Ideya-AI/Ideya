Content

  • 6–8 stat cards. Each: label, big value, one-line note, source.
  • Smart title = the metric, not a sentence. “Deaths per TWh,” not “How dangerous is it?”
  • Facts most positions accept — no contested numbers here (those live in Questions).
  • Comparative context baked in (“Coal ~24.6”), not standalone figures.

Design

  • Each fact maps to one chart type by its shape (see vocabulary).
  • Charts are ink + single green; the subject is the only green bar.
  • Tabular figures (Inter) for all numbers; Jakarta 800 for the hero value.
  • Tile = flat, 1px border, no shadow. Equal height in a row.

Interaction & expansion

  • Static by default — readable with zero interaction (it's a poster too).
  • Tap a tile → its source + methods expand inline (no modal on desktop).
  • Depth grows the tile: viz → +note+source → +methods/“go further.”
  • Layout per medium: poster 2-up hero + small; web 4-col; mobile 2-col, carousel optional.
